## The injection, before and after, on a bare container

`docker run` of that image with `backends/tests/conformance/wiremock/orange`
mounted at `/home/wiremock` and `--global-response-templating`, then the
hosted page requested with `return` and `cancel` both set to a URL carrying a
quote, angle brackets, an ampersand and a space. The hidden inputs were read
back with Python's `html.parser` (what a browser's parser would see), the form
was submitted GET with those values form-encoded plus `msisdn`, and both links
were followed.

**Before** (the mappings on `ea469b40`), `return=https://m.test/back?q="x"&y=<z> w`:

```text
RAW: <input type="hidden" name="return" value="https://m.test/back?q="x"&y=<z> w">
parsed hidden inputs: [('return', 'https://m.test/back?q='), ('cancel', 'https://m.test/cancel?q=')]
form submit -> 302 'https://m.test/back?q=' MISMATCH
#pay link -> 302 'https://m.test/back?q="x"&y=<z> w' MATCH
#cancel link -> 302 'https://m.test/cancel?q="c"&y=<c> w' MATCH
```

**After** (this branch), same URL:

```text
RAW: <input type="hidden" name="return" value="https%3A%2F%2Fm.test%2Fback%3Fq%3D%22x%22%26y%3D%3Cz%3E+w">
form submit -> 302 'https://m.test/back?q="x"&y=<z> w' MATCH
#pay link -> 302 'https://m.test/back?q="x"&y=<z> w' MATCH
#cancel link -> 302 'https://m.test/cancel?q="c"&y=<c> w' MATCH
```

The same with `msisdn=237600000400` (a test-number arm in
`demo-outcomes.json`): `MATCH` on all three. With `curl` alone, the form's
double-encoded query (`return=https%253A%252F%252Fm.test…%2Bw&…&msisdn=237600000000`)
answered `HTTP/1.1 302 Found` with `Location: https://m.test/back?q="x"&y=<z> w`,
and `/__admin/scenarios` then read `orange-hosted-page-payer payer-paid`.
