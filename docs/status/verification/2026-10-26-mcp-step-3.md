## What was measured before it was built, and changed the design

- **CrateStack 0.16's procedure router mounts every procedure, and no
  attribute keeps one off REST.** The source is
  `cratestack-parser-0.16.0/src/validate/procedure_attributes.rs`'s closed
  list. So `/dash/v1/$procs` gained an allowlist.
  `a_merchant_mcp_procedure_is_not_served_to_the_dashboard` passes with it.
  With the allowlist layer removed, the same test fails with
  `left: 403, right: 404`, whose body is the procedure policy's
  `FORBIDDEN`. That shows the inner wall holds on its own.
- **CrateStack 0.16 refuses a tool whose input or output holds a `Json`
  field.** So metadata and payer fields are name/value lists.
- **The OP dropped RFC 8707 `resource`.** This was measured by sending
  `resource=` instead of `audience=`. The OP answered `200` with a token that
  `/mcp/v1` then refused with `401`.
  `op::token::apply_resource_indicator` fixes it. With the fix stubbed out,
  `an_rfc_8707_resource_is_the_audience_it_names` fails with
  `left: 401, right: 200`.
- **The `/v1` refund object has a `fee` field.** The first `McpRefund` did not
  declare it, and `the_refund_tools_reach_v1s_refund_code` failed on that
  until it was added.
