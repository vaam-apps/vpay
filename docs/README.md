# Documentation

Read only the document that answers the task at hand:

| Need                                                | Read                                                |
| --------------------------------------------------- | --------------------------------------------------- |
| Current product limits                              | [status.md](status.md)                              |
| What worked on a given day, and what a gate printed | [status/](status/README.md)                         |
| HTTP contract                                       | [api/](api/README.md)                               |
| A cross-component invariant                         | [flows/](flows/README.md)                           |
| A recorded architectural decision                   | [adr/](adr/)                                        |
| An operator procedure                               | [runbooks/](runbooks/README.md)                     |
| SDK support                                         | [sdks/parity.md](sdks/parity.md)                    |
| Code rationale that is not clear from source        | [reference/](reference/README.md)                   |
| A maintainer choice not yet made                    | [open-decisions.md](open-decisions.md)              |
| An undecided proposal                               | [rfc/](rfc/README.md)                               |
| What a past step or experiment actually did         | [plans/](plans/) — dated records, not current truth |

For a safe first change, start with [CONTRIBUTING.md](../CONTRIBUTING.md), then
read the code and tests you will change. Do not read this directory in order.
